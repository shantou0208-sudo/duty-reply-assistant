# 值班回复助手 v7 · Mini Bar

v7 是纯 Windows 桌面版，适合微信、网页聊天框、飞书客户端、记事本等能够正常使用 `Ctrl+V` 的输入框。

当前更新标识：`2026-07-28e`。正确启动后，主横条只有“命令库、管理、隐藏”三个按钮。

本次界面更新删除了主横条左侧状态文字，并将命令搜索窗口改成类似网页扩展的单列卡片布局。每条卡片直接显示分类、名称、命令和说明。

性能优化版会将命令索引缓存在内存中，并且每次只显示最相关的 8 张卡片。若匹配结果较多，继续输入关键词即可缩小范围。

丝滑优化版进一步取消了多控件卡片：全部结果由一个 Canvas 直接绘制，并在程序启动后后台预建隐藏的命令窗口。首次按快捷键不再临时搭建页面，输入后也在当前空闲帧立即重绘。

## v7 新增内容

- 隐藏后常驻 Windows 右下角系统托盘。
- 托盘菜单可显示横条、打开管理、隐藏或彻底退出。
- 提供无 CMD 黑框的 `启动助手.vbs`。
- 在桌面助手中加入 Linux、Conda 和 Slurm 命令库。
- 内置 100 余条命令、参数和作业脚本模板。
- 按可自定义的全局快捷键直接打开独立命令搜索框。
- 支持中文、英文、命令名称和关键词检索。
- 命令可以自行新增、编辑和删除。
- 保留 v6 的不限数量快捷回复、微信可靠粘贴和礼貌润色。

## 第一次使用

### 1. 安装托盘依赖

只需执行一次：

```text
install_dependencies.bat
```

它会安装：

```text
pystray
Pillow
```

这些库用于显示右下角托盘图标。

### 2. 无黑框启动

以后请双击：

```text
启动助手.vbs
```

使用这个文件启动时不会出现 CMD 黑框。

`run.bat` 也改为使用 `pythonw.exe`，通常只会短暂闪一下启动窗口。最安静的方式仍然是 `启动助手.vbs` 或打包后的 EXE。

## 隐藏后去哪里找

点击横条上的“隐藏”或标题栏 X 后，程序仍在后台运行：

1. 查看 Windows 桌面右下角通知区域。
2. 如果没有直接看到，点击 `^` 展开隐藏图标。
3. 找到“值班回复助手 v7”。
4. 双击图标显示横条，或右键打开菜单。

也可以按默认快捷键：

```text
Ctrl+Alt+Space
```

重新显示横条。

要彻底退出，请右键托盘图标并选择“退出”。

## 常用回复和快捷键

每条回复都可以设置独立的完整快捷键，数量不限。操作路径：

```text
管理 → 常用回复 → 新增/编辑
```

支持的示例：

```text
Ctrl+Alt+Q
Ctrl+Shift+F2
Alt+Shift+8
Ctrl+Alt+Shift+M
```

若组合被微信、输入法或 Windows 占用，管理窗口标题会显示注册失败。

## Linux、Conda 和 Slurm 命令库

默认按：

```text
Ctrl+Alt+K
```

会直接弹出独立命令搜索框，不需要先打开助手主界面：

- `↑`、`↓` 选择结果
- Enter 复制命令并关闭
- Esc 关闭
- 双击结果也可复制

快捷键可在这里修改：

```text
管理 → 设置 → 打开 Linux/Conda/Slurm 命令搜索
```

主横条不再提供话术搜索框，只保留“命令库、管理、隐藏”。常用回复继续通过各自的全局快捷键直接使用。

完整命令管理页面位于：

```text
管理 → 命令库
```

命令库分为：

- Linux 文件、文本、资源、进程、权限、压缩、网络和环境
- Conda 环境与软件包管理
- Slurm 作业查询、提交和控制
- Slurm 常用 `#SBATCH` 参数
- CPU MPI 和 GPU 作业脚本模板
- 用户自定义命令

### 搜索

搜索框支持：

```text
怎么看节点
文件夹大小
显存
动态库
创建conda环境
作业为什么排队
ntasks
gres
squeue
```

选中结果后点击“复制命令”，或者双击结果。按 Enter 会复制当前第一条结果。

### 自己增加新命令

1. 进入“管理 → 命令库”。
2. 点击“新增”。
3. 填写分类、名称、命令、说明和搜索关键词。
4. 点击保存。

新增内容保存在：

```text
%APPDATA%\DutyReplyAssistant\assistant.db
```

以后覆盖程序代码或升级版本不会删除。

内置命令也可以编辑或删除。涉及删除、权限、作业取消等操作时，请先确认路径、作业号和集群规则；程序只复制命令，不会自动执行。

### 关于“官方接口”

旧网页扩展并没有连接 Linux、Conda 或 Slurm 的官方 API，而是将 50 条静态命令写在本地 JavaScript 文件中。v7 当前内置 113 条，本地库反而更多。

Linux、Conda 和 Slurm 没有一个能够统一返回“全部命令及中文解释”的公共 API。运行时抓取官网还会受网络、官网页面变化和单位访问策略影响。因此 v7 采用可离线搜索、允许自行修订的本地命令库，也不会把你的搜索词发送给外部网站。

## 礼貌替换

普通 Python 程序无法稳定取得中文输入法最终提交的每一个汉字，因此 v7 不宣称能够在所有软件中实时把“你”改成“您”。

可靠方式：

1. 在微信或网页输入框选中需要修改的文字。
2. 按默认 `Ctrl+Alt+R`。
3. 程序按照本地规则替换并粘贴回原位置。

规则位于：

```text
管理 → 礼貌润色 → 编辑替换规则
```

## 打包 EXE

双击：

```text
build_exe.bat
```

完成后在 `dist` 中生成：

```text
值班回复助手_v7.exe
```

打包脚本会自动包含托盘依赖。个人 EXE 没有商业数字签名，Windows 可能显示未知发布者提示。

## 微信中无法使用时

- 确认管理窗口标题显示快捷键已经生效。
- 在微信输入框手动测试 `Ctrl+V`。
- 完全退出旧版本，避免两个版本抢占相同热键。
- 如果微信以管理员身份运行，助手也要以相同权限运行。
- 程序不会自动点击发送，粘贴后请检查内容。
