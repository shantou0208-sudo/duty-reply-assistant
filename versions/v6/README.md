# 值班回复助手 v6 · Mini Bar

v6 是纯 Windows 桌面版，不需要浏览器扩展。适合微信、普通网页聊天框、飞书客户端、记事本等能够正常使用 `Ctrl+V` 的输入框。

## v6 的主要变化

- 主窗口缩小为输入法候选栏风格的单行横条。
- 每条回复都可以设置自己的完整快捷键。
- 快捷回复数量不再限制为 9 条。
- 修复热键触发后 Ctrl、Alt 或 Shift 尚未松开便发送粘贴的问题。
- 在热键触发瞬间记录前台窗口，减少微信窗口焦点丢失。
- 保留本地礼貌替换规则。
- 不再包含浏览器扩展和 Linux/HPC 网页面板。
- 自动继承 v1-v5 保存在 `%APPDATA%\DutyReplyAssistant` 中的话术数据。

## 启动

双击：

```text
run.bat
```

如果同一目录存在 `.venv`，启动脚本会自动使用；否则使用系统中的 `py`。

横条上的“隐藏”会把窗口收起，按默认 `Ctrl+Alt+Space` 可重新显示。点击标题栏右上角的 X 才会完全退出程序。

## 在微信中测试

1. 启动助手。
2. 点击“管理”，确认窗口标题显示全局快捷键已经生效。
3. 打开微信聊天输入框并点击一次，使光标出现。
4. 按某条回复对应的快捷键，例如 `Ctrl+Alt+1`。
5. 完整松开按键。
6. 话术应粘贴到微信输入框，但不会自动发送。

若仍无反应：

- 在管理页选中该回复，点击“测试粘贴”。回到微信手动按 `Ctrl+V`。
- 如果手动 `Ctrl+V` 也不能粘贴，问题来自微信当前输入框或剪贴板权限。
- 如果手动粘贴可以，但快捷键不行，检查管理窗口标题是否提示快捷键被占用。
- 如果微信以管理员身份运行，助手也必须以相同权限运行，否则 Windows 会阻止模拟输入。

## 不限数量地添加快捷回复

1. 点击横条上的“管理”。
2. 进入“常用回复”。
3. 点击“新增”。
4. 填写名称、回复内容、快捷键和搜索关键词。
5. 快捷键可以使用：

```text
Ctrl+Alt+Q
Ctrl+Shift+F2
Alt+Shift+8
Ctrl+Alt+Shift+M
```

每条回复都可以使用不同组合，条目数量不受 1～9 限制。Windows 能注册的实际数量取决于系统资源和其他软件占用情况。

## 横条搜索

在横条中输入分类、话术内容或关键词，按 Enter 会粘贴第一条匹配结果。建议给话术设置简短关键词，例如：

```text
确认
排队
截图
完成
```

## 礼貌替换

普通 Python 程序无法稳定取得中文输入法最终提交的每一个汉字，因此 v6 不宣称能够在所有软件里自动把刚输入的“你”实时改为“您”。

可靠用法：

1. 在微信或网页输入框中选中需要修改的文字。
2. 按默认快捷键 `Ctrl+Alt+R`。
3. 程序复制选中文字，按本地规则替换，再粘贴回原位置。

替换规则可以在“管理 → 礼貌润色 → 编辑替换规则”中修改。

如果未来必须在所有软件中逐字监听中文，需要单独开发并安装 Windows TSF/IME 输入法模块。这与普通桌面小程序不是同一复杂度，也需要额外考虑签名、权限和单位安全政策。

## 修改快捷键

- 每条回复：进入“管理 → 常用回复”，双击对应回复。
- 显示/隐藏横条：进入“管理 → 设置”。
- 润色选中文字：进入“管理 → 设置”。

保存后程序会立即重新注册快捷键。若组合已被微信、输入法或 Windows 占用，管理窗口标题会显示失败原因。

## 打包 EXE

双击：

```text
build_exe.bat
```

完成后在 `dist` 中生成：

```text
值班回复助手_v6.exe
```

个人打包的 EXE 没有商业数字签名，Windows 可能显示未知发布者或智能应用控制提示。
