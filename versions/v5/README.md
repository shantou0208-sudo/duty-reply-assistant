# 值班回复助手 v5

v5 包含两部分：

1. **Windows 桌面助手**：面向微信、飞书客户端、记事本等 Windows 软件。
2. **Edge/Chrome 浏览器扩展**：面向工作网页，提供礼貌替换、网页话术和 Linux/HPC 命令库。

桌面和网页快捷键分别配置，避免互相争抢。

## 一、从 v4 更新

不需要删除或重建 `.venv`。

1. 完全退出正在运行的旧版桌面助手。
2. 把旧的 `duty_assistant.py` 改名为 `duty_assistant_v4.py` 作为备份。
3. 将 v5 压缩包中的全部文件复制到原项目目录，覆盖同名文件。
4. 保留原目录中的 `.venv`。
5. 双击新版 `run.bat`。
6. 打开 `edge://extensions`，在扩展卡片上点击“重新加载”。
7. 确认扩展版本为 `5.0.0`。
8. 刷新已经打开的工作网页。

个人话术和桌面配置保存在 `%APPDATA%\DutyReplyAssistant`，覆盖项目代码不会删除。

## 二、桌面助手快捷键

双击：

```text
run.bat
```

打开桌面助手。v5 推荐的默认组合为：

| 功能 | 默认快捷键 |
|---|---|
| 常用话术1～9 | `Ctrl+Alt+1～9` |
| 显示或隐藏助手 | `Ctrl+Alt+Space` |
| 润色外部软件中选中的文字 | `Ctrl+Alt+R` |

桌面话术从旧版的 `Alt+1～9` 改为 `Ctrl+Alt+1～9`，用于减少与微信自身快捷键的冲突。

### 修改桌面快捷键

1. 打开桌面助手。
2. 切换到“快捷键”页面。
3. 每个功能分别选择：
   - 修饰键：`Ctrl+Alt`、`Ctrl+Shift`、`Alt+Shift`或`Ctrl+Alt+Shift`
   - 主键：数字、字母、`F1～F12`或`Space`
4. 点击“保存并重新注册”。
5. 查看软件底部状态栏。

如果显示：

```text
全部桌面快捷键已生效
```

说明设置成功。

如果显示：

```text
快捷键注册失败：reply_1（Ctrl+Alt+1）
```

说明该组合已经被微信、输入法、Windows 或其他程序占用。返回“快捷键”页面换一组，再次保存。

软件也会阻止两个助手功能设置成完全相同的快捷键。

### 恢复推荐快捷键

1. 进入“快捷键”页面。
2. 点击“恢复推荐组合”。
3. 点击“保存并重新注册”。

### 修改某个编号对应的话术

1. 进入“常用话术”页面。
2. 选择一条话术。
3. 点击“编辑”。
4. 将快捷键编号设置为 `1～9`。
5. 保存。

“快捷键”页面决定按键组合，“常用话术”页面决定这个编号对应什么文字。

## 三、网页话术快捷键

网页默认仍使用：

```text
Ctrl+Shift+1～9
```

### 修改网页组合键

1. 点击浏览器工具栏上的“值班回复助手”图标。
2. 点击“编辑规则和话术”。
3. 找到“网页快捷话术”。
4. 在“话术组合键”中选择：
   - `Ctrl+Shift+数字`，默认推荐
   - `Ctrl+Alt+数字`
   - `Alt+Shift+数字`
   - `Ctrl+Alt+Shift+数字`
5. 点击“保存设置”。
6. 刷新工作网页。

九条话术会统一使用选中的修饰键。例如选择 `Ctrl+Alt` 后，对应快捷键变为：

```text
Ctrl+Alt+1
Ctrl+Alt+2
……
Ctrl+Alt+9
```

建议桌面助手和浏览器扩展使用不同组合。例如：

```text
桌面助手：Ctrl+Alt+1～9
网页扩展：Ctrl+Shift+1～9
```

## 四、Linux/HPC 命令库快捷键

Linux知识库默认使用：

```text
Ctrl+Shift+K
```

该快捷键由 Edge 的扩展快捷键系统管理，不能在莫兰迪设置页面直接修改。

修改方法：

1. 在 Edge 地址栏输入 `edge://extensions/shortcuts`。
2. 找到“值班回复助手 · 网页增强”。
3. 找到“打开 Linux/HPC 命令搜索”。
4. 点击快捷键框。
5. 按下新的组合键，例如 `Ctrl+Shift+Y`。

也可以点击扩展图标中的“打开 Linux 命令库”，完全不用快捷键。

命令面板支持中文和英文搜索，例如：

```text
怎么看节点
作业为什么排队
显存
文件夹大小
动态库
squeue
tail
grep
```

面板操作：

| 操作 | 功能 |
|---|---|
| 输入中文或英文 | 筛选命令 |
| `↑`、`↓` | 选择结果 |
| Enter | 复制命令 |
| Esc | 关闭面板 |

## 五、安装浏览器扩展

### Microsoft Edge

1. 在地址栏打开 `edge://extensions`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择项目中的 `browser_extension` 文件夹。
5. 选择的文件夹中应当直接包含 `manifest.json`。
6. 固定“值班回复助手 · 网页增强”到工具栏。

### Google Chrome

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `browser_extension` 文件夹。

## 六、在工作网站启用

1. 打开工作网页。
2. 点击扩展图标。
3. 打开“在此网站启用”。
4. 保持“自动礼貌替换”开启。
5. 刷新网页。
6. 先在不会直接发送消息的位置测试。

扩展按域名授权。网页话术和礼貌替换只在主动允许的网站生效。

## 七、本地测试

1. 双击 `start_test_page.bat`。
2. 打开 `http://localhost:8765/test_page.html`。
3. 点击扩展图标并允许 `localhost`。
4. 刷新页面。
5. 输入“你发一下截图”，检查礼貌替换。
6. 测试当前设置的网页话术快捷键。
7. 测试结束后，在服务器窗口按 `Ctrl+C`。

## 八、打包桌面 EXE

双击：

```text
build_exe.bat
```

完成后生成：

```text
dist\值班回复助手.exe
```

个人打包的 EXE 没有商业数字签名，Windows 可能显示未知发布者或智能应用控制提示。

## 九、快捷键冲突排查

| 现象 | 处理方法 |
|---|---|
| 桌面助手状态栏显示注册失败 | 在“快捷键”页面更换组合并重新保存 |
| 微信执行了自己的操作 | 不使用旧版 `Alt+数字`，改用 `Ctrl+Alt` 或三修饰键 |
| 网页某些组合无效 | 更换网页话术组合，保存后刷新网页 |
| Linux知识库快捷键无效 | 到 `edge://extensions/shortcuts` 重新分配 |
| 点击扩展按钮能打开，但快捷键不能 | 功能正常，只是快捷键被占用 |
| Edge地址栏或 `edge://` 页面不能使用 | 浏览器安全限制，扩展无法注入内部页面 |

## 十、已知限制

- 特殊富文本编辑器、Canvas输入框和受保护 iframe 可能无法插入话术。
- 浏览器地址栏、Edge设置页、新标签页和部分内置PDF页面不允许扩展修改。
- 自动礼貌替换默认跳过密码框和代码块。
- 工具不会自动点击“发送”，需要人工检查后发送。
- 单位策略如果禁止开发者模式扩展，需要由管理员授权。
